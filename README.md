# WarspearChatTranslate · Warspear 聊天翻译器

[![版本](https://img.shields.io/github/v/release/Madtree530/WarspearChatTranslate)](https://github.com/Madtree530/WarspearChatTranslate/releases/latest)
[![MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Windows 桌面浮窗，通过 OCR 读取 Warspear Online 客户端中当前可见的聊天，翻译成**简体中文**。可框选世界、交易、私密、队伍、区域和公会聊天面板，无需依赖 Discord 转发频道。

[下载最新版本](https://github.com/Madtree530/WarspearChatTranslate/releases/latest) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/Madtree530/WarspearChatTranslate/issues)

## 安装与启动

本版本是 **Python 启动包，需要 Python 3.12 64 位，不含独立 EXE**。已在 Windows / Python 3.12.10 x64 上验证。

1. 从 Releases 下载 `WarspearChatTranslate-v1.0.0-windows-python.zip`，完整解压到可写目录。
2. 从 [Python 官网](https://www.python.org/downloads/windows/)安装 Python 3.12 64 位，勾选 **Add python.exe to PATH**。
3. 双击 `run.bat`。首次启动自动建立 `.venv` 并联网安装依赖，请等待安装完成。
4. 点击「框选区域」，框住聊天列表，建议同时包含顶栏的中文频道标题。
5. 智能模式默认开启：看到标题后开始翻译，标题消失约 2–3 秒后停止。也可关闭智能模式，手动点「开始 / 停止」。

俄语、泰语识别模型已附在仓库与发布包内。模型缺失时程序会尝试下载。翻译本身需要联网，网络环境须能访问 Bing。

**更新已有安装：**先关闭旧窗口，备份自己的 `config.json` 和 `glossary.json`；解压新版到新目录，再复制这两个文件过去，最后运行新版 `run.bat`。不要直接覆盖已修改的词表。

## 主要功能

- **多频道阅读：**翻译屏幕上当前可见的聊天，不限于世界频道。不会获取未打开或未显示的频道消息。
- **多语言：**英语、俄语、泰语、韩语、越南语，以及部分芬兰语、葡萄牙语聊天译为简体中文。俄语和泰语使用专用 OCR 识别模型；拉丁字母语言共用主模型，语种粗检和翻译效果可能有差异。
- **智能开停：**识别「世界 / 交易 / 私密 / 队伍 / 区域 / 公会聊天」中文标题；「信息」页签不触发。其它界面语言请关闭智能模式后手动开始。
- **减少误译：**过滤「信息：」「系统：」「公告：」「提示：」等中文系统消息；两次独立 OCR 确认后翻译，减少抖动、重复和低置信度误识别。
- **俄服识别修正：**避免把西里尔字母读成拉丁字母、夹汉字跳过翻译；拒绝俄文原样返回被算作中文成功。
- **低 CPU 设计：**单线程推理、三种识别共用文字检测、静止画面缓存；智能标题检测在后台运行。
- **可调整浮窗：**置顶、字号、拖动、四边与四角缩放、最小化、迷你「译」恢复按钮。
- **可编辑词表：**工具栏「词表」可增删改游戏缩写，修改后清空翻译缓存。

## 初始术语表

`glossary.json` 包含作者平时使用的术语，覆盖程序内置同名项，用户可按服务器习惯修改。内置词表含 `signs → 不朽符号`、`dmg 3 → 三级武器强化材料`、`pm → 私聊` 等。

初始词表也包含特定服务器、公会和日常活动用语。例如 `200k → 天空日常boss`、`85k → 图三日常`，**这些词条不一定代表交易金额**；使用其它服务器前建议在「词表」中检查、删除或修改。

词表按整词匹配，不会把普通单词切碎。不要给 `and`、`or`、`the` 等常用连接词设置游戏术语替换。

## CPU 与翻译效果

在 16 逻辑核机器上，同一张 1935×1852 截图启用聊天扫描与智能模式、回放约 12 秒，平均总 CPU 占用从旧版 **41.6% 降至 3.7%**。加入俄语模型后的另一张截图，单次热 OCR 约 2.62 秒、消耗 2.59 CPU 秒，相当于识别期间约 **6.2%** 的总 CPU；静止画面缓存约 0.006 秒。

俄服截图回放中，18 条玩家消息有 16 条返回中文、两条短串失败，四条系统公告未送翻。这不代表译文语义完全准确，也不是实时游戏测量；不同 CPU、聊天数量、框选大小和背景动画会影响实际表现。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示找不到 Python | 安装 Python 3.12 64 位并加入 PATH，然后重新运行 `run.bat` |
| 首次依赖安装失败 | 检查能否访问 PyPI，按窗口错误提示处理后重新运行 |
| 自动翻译不启动 | 框选时包含中文频道标题；其它界面语言使用手动开始 |
| 没有识别到聊天 | 调整框选范围，保证完整包含「玩家名：正文」和清晰字体 |
| CPU 仍较高 | 缩小到聊天面板范围，提高游戏聊天背景不透明度，减少透出的动画 |
| 翻译失败或限流 | 稍等再试，程序会自动切换 Bing 主机；不要连续反复启动自检 |
| 提示俄语识别暂不可用 | 检查 `models/` 文件；若下载失败，恢复网络后重启 |
| 表情或极短缩写识别错误 | 属于 OCR 的已知限制；确定含义的术语可加入词表 |
| 窗口找不到 | 查看任务栏或右下角绿色「译」按钮 |
| 显示器 / DPI 改动后区域偏了 | 重新点击「框选区域」 |

框选尽量只包含聊天列表和标题，少带输入框、表情栏或其它 UI。插件会忽略中文系统公告；其它语言的公告标签不保证过滤。

## 数据与已知限制

OCR 在本地运行；需要翻译的聊天正文会发送至 Bing，**截图不会上传**。框选范围与窗口设置保存在本机 `config.json`，不会随仓库发布。初始词表公开提供，之后的修改保存在各使用者自己的目录。

本工具独立于游戏客户端，不读取游戏内存、不捕获游戏封包、不需要游戏账号密码，也不依赖本地大语言模型或付费 API Key。

OCR 无法保证完全准确：半透明透字、图标、非常短的消息、俄服缩写和西里尔字母玩家名仍可能误识或误译。Bing 网页接口可能因限流或改版失效。请按游戏规则使用辅助工具。

## 自检与开发

联网自检：

```bat
run.bat --selftest
```

离线回归（依赖已安装、模型文件齐全后不需联网）：

```bat
.venv\Scripts\python.exe -X utf8 -m unittest discover -v
```

v1.0.0 包含 37 项回归测试。开发约束与反馈说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。`wptrans.py` 为主程序，`models/` 为模型，`tests/fixtures/` 为截图回归输入。`.venv` 和 `config.json` 均为本机运行时文件。
