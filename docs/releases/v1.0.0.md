# v1.0.0 · 首次公开发布

Warspear Online Windows 聊天翻译浮窗：读取客户端中当前可见的聊天，译成简体中文。世界、交易、私密、队伍、区域、公会面板均可框选使用。

## 下载和启动

1. 下载 `WarspearChatTranslate-v1.0.0-windows-python.zip`，解压到可写目录。
2. 安装 **Python 3.12 64 位**，安装时勾选 **Add python.exe to PATH**。
3. 双击 `run.bat`，首次会联网安装依赖。
4. 点击「框选区域」，包含聊天列表和中文频道标题；智能模式会自动开始。其它界面语言可关闭智能模式并手动开始。

**这是 Python 启动包，不含独立 EXE。** 包内已附俄语/泰语 OCR 模型和初始术语表。已有用户更新时请保留自己的 `config.json` 和 `glossary.json`。

## 本版内容

- 专用俄语和泰语识别，修复俄服大部分消息原文输出。
- 单线程 OCR、共用检测、静止画面缓存，减少 CPU 占用。
- 系统公告过滤、两帧确认、译文去重与失败提示。
- 可调整置顶窗口、字号、框选区域和术语表。

37 项离线回归通过，联网自检失败数 0。用户俄服截图回放：18 条玩家消息中 16 条返回中文，另两条短串失败；四条系统公告未送翻。单次识别期间，16 逻辑核机器总 CPU 约 6.2%。这些是截图测试数据，不能保证其它机器或实时游戏中相同的占用或翻译质量。

## 已知限制

短消息、表情、半透明背景透字、俄服缩写及西里尔字母玩家名仍可能识别不准；游戏黑话需按服务器修改词表。词表中的 `200k` 和 `85k` 是特定日常活动用语，不一定代表金额。

OCR 在本地运行，需要翻译的聊天正文会发送至 Bing；截图不上传。翻译需联网，网页接口限流或变动时可能暂时失败。本项目为玩家制作的独立工具。

源码与初始术语表采用 MIT 许可，第三方 OCR 模型保留其 Apache 2.0 许可。校验下载文件可使用同页的 `SHA256SUMS.txt`。
